When to use each case style

UPPERCASE and lowercase are useful for headings or normalising data. Title Case capitalises the first letter of each major word, which is common for headlines. Sentence case capitalises only the first letter of the first word, matching normal prose. camelCase is common in programming for variable names, and Alternating Case is a playful style sometimes used for emphasis.

Frequently asked questions

Does the converter change punctuation or numbers?

No, punctuation, numbers and symbols are left untouched — only the casing of letters is changed.

Is my text stored anywhere?

No. All conversion happens locally in your browser using JavaScript, and nothing is uploaded or saved.
