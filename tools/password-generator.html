Password Generator

Generate a strong, random password using your browser's secure random number generator. Adjust length and character types to match any site's rules.

Passwords are generated locally using crypto.getRandomValues() and are never transmitted or stored.

Strength: —

What makes a password strong

A strong password is long, unpredictable and uses a mix of character types. Length matters more than complexity — a 16-character password with mixed character types is far harder to guess or brute-force than a short, complex one. Avoid reusing the same password across multiple sites, and consider a password manager to store the ones this tool generates.

Frequently asked questions

Is this password generator secure?

Yes. It uses the Web Crypto API's crypto.getRandomValues(), a cryptographically secure random number source built into your browser, rather than JavaScript's ordinary Math.random().

Are generated passwords sent anywhere?

No. Passwords are generated and displayed entirely on your device. This tool has no server component and makes no network requests.

Why exclude ambiguous characters?

Characters like lowercase L, uppercase I, and the digits 1 and 0 can look similar in some fonts. Excluding them makes a password easier to type accurately when read from a screen or paper.
