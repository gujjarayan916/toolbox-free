How this QR code generator works

The text you enter is encoded directly in your browser using a JavaScript implementation of the QR code algorithm — the same error-correction and data-encoding steps a QR standard defines — and the result is drawn to a canvas. Because the encoding happens on your device, this tool works even without an internet connection once the page has loaded, and no third-party QR service ever sees the content of your code.

Frequently asked questions

What can I put in a QR code?

Any text works, including plain website URLs, email addresses (as mailto:), phone numbers (as tel:) or Wi-Fi credentials in the standard Wi-Fi QR format.

Why does the code change size and pattern as I type more text?

QR codes come in versions with different grid sizes. Longer text needs a larger grid to store, so the generator automatically picks the smallest version that fits your content.

Which error correction level should I choose?

Medium (M) is a good default for most uses. Choose High (H) if the code will be printed small, exposed to wear, or if you plan to place a logo over the middle of it.
